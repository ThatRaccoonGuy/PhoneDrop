iPhone / iPad

  1. Use Safari (other browsers can't install profiles). Tap the button above and allow the profile download; if it lands in the Files app instead, open it from there.
  2. Settings → Profile Downloaded → Install.
  3. Settings → General → About → Certificate Trust Settings → enable “PhoneDrop Root CA”.

Android

  1. Settings → Security → Encryption & credentials → Install a certificate → CA certificate.
  2. Pick the downloaded file.
